# Security policy

## Supported versions

Security fixes are applied to the current `main` branch. No released version is
currently designated for long-term support.

## Reporting a vulnerability

Use GitHub's **Report a vulnerability** form in the repository Security tab.
Do not disclose a suspected vulnerability, credential, customer content or
server configuration in a public Issue or pull request.

We will acknowledge a complete report, assess impact, and coordinate a fix and
disclosure timeline. Please include only the minimum synthetic reproduction
needed to demonstrate the problem.
